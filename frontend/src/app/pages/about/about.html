About Our Books Library

Welcome to Books Library, a full-stack web application designed to make managing your book collection simple and convenient.

Browse your collection, add new books, update existing entries, delete books you no longer need, and search instantly by title or author.

Technologies Used

  • Angular — Frontend interface and navigation
  • ASP.NET Core — Backend REST API
  • Entity Framework Core — Database operations
  • SQLite — Database storage

This project demonstrates full-stack development, including CRUD operations, API integration, responsive design, and client-side routing.
